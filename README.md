# Pokémon Explorer

A simple Pokémon browser built with Next.js and Chakra UI. Browse all 151 Generation I Pokémon, search by name or number, and view each Pokémon's stats, types, abilities, and moves.

Data is fetched from the [PokéAPI](https://pokeapi.co/).

## Tech Stack

- [Next.js 16](https://nextjs.org/) — App Router, server components, ISR
- [Chakra UI v3](https://chakra-ui.com/) — component library
- [PokéAPI](https://pokeapi.co/) — Pokémon data

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Other Commands

```bash
npm run build   # production build
npm run start   # start production server
npm run lint    # run ESLint
```
